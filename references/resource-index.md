# 本地资源索引（owner 自管，未联网）

> 用途：被 `scripts/build_upskill_brief.py` 读取，把「方向性缺口」映射到**你已收藏的**
> 本地学习资源。本工具**不联网**、不替你搜课程，只做「缺口 → 你已有资源」的桥接。
>
> 维护方式：把下面的示例替换成你自己的链接即可。`build_upskill_brief.py` 按二级标题
> （`##`）判断维度，把资源挂到对应维度下。标题含以下关键字即归入该维度：
> `hard`/`硬` → 硬技能；`soft`/`软` → 软技能；`tool`/`工具` → 工具链；
> `domain`/`领域`/`业务` → 领域；`credential`/`证书`/`学历` → 证书。
>
> 链接格式：`- [标题](url) — 备注`。备注可选（备注里可含 `[]` 之外的任意文字）。
