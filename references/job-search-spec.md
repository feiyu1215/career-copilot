# 求职 Spec 模板（规划模式产出）

> 规划模式：把模糊目标落成结构化 spec + 周度 tickets。
> 生成后存 `career-plan.md`，并挑本周 tickets 同步进 `career-context.md` 待办。

## 求职 Spec 六要素

1. **目标岗位**：具体岗位 + 方向（如「大厂后端 / AI 产品」）
2. **时间线**：总周期 + 关键节点（如「8 周内完成 3 家面试」）
3. **必需材料**：简历定稿 / 作品集 / 推荐信 / 内推渠道
4. **目标公司清单**：Tier 分级 + 优先级（A 冲刺 / B 稳健 / C 保底）
5. **成功标准**：可测（如「拿到 ≥1 个 offer / 进入 ≥3 终面」）
6. **风险与依赖**：时间冲突 / 材料缺口 / 需他人配合（内推人）

## 周度 Tickets 模板

```markdown
# 第 N 周（起止日期）
- [ ] 动作1（依赖：___；验收：___）
- [ ] 动作2（依赖：___；验收：___）
- 本周里程碑：___
```

## 使用约定

- 规划模式生成 spec + tickets 后存 `career-plan.md`。
- 每周回顾：完成项归档，未完成项顺延或重排；变更同步 `career-context.md`。
- spec 是活文档：方向变了先改 spec 再行动，不默默偏离。
- 不替用户投递、不代做薪资谈判（见 SKILL.md 红线）。
