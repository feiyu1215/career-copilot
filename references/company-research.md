# 公司 / 岗位调研模板（调研模式产出）

> 调研模式：拉公开信息 → 带引用的 markdown。用于投递前判断「这公司 / 岗值不值得」。
> 对应 Matt Pocock `research` 思想；公开信息优先 `web_search`，不爬需登录的内部系统。

## 调研维度（按重要性排序）

1. **业务**：公司 / 部门做什么、商业模式、近期动态（融资 / 组织调整 / 战略方向）
2. **岗位真实要求**：JD 字面要求 vs 团队实际痛点；汇报线；技术栈
3. **面试官画像**：从公开渠道（技术博客 / 脉脉 / 看准）拼出可能面试官的背景与风格
4. **口碑信号**：员工真实评价（看准 / 脉脉 / 小红书），重点看「管理 / 加班 / 成长」三类
5. **匹配度**：对照用户 `boundary_profile` 的迁移距离（近 / 中 / 远）

## 输出格式

```markdown
# 调研：<公司 - 岗位>
- 业务：___（来源：___）
- 岗位真实要求：___（来源：___）
- 面试官可能画像：___（来源：___）
- 口碑信号：___（来源：___）
- 与你匹配：___（迁移距离：近 / 中 / 远）
- 建议：投 / 观望 / 不投，因为 ___
```

## 原则

- **引用来源**；未能证实的表述标注「未证实」，不把传闻当事实。
- **不记录隐私**（同 SKILL.md 红线）：不写具体薪资数字、真名、身份证号。
- 公开信息优先；不爬需登录的内部系统，不代用户做背调越界动作。
- 调研结论用于辅助决策，最终投不投由用户定。
