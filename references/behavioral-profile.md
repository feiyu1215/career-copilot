# 行为画像（Behavioral Profile）

> 用途：把「你是谁、怎么工作、在什么环境里最强」说清楚，让简历 / 求职信 / 面试答案**自带行为优势**，
> 而不是只堆硬技能。本文件是**画像模板 + JD 关键词↔行为风格映射 + 织入指引**，不强制任何测评。
> 配套流程见 `SKILL.md` 面试 / 简历模块——在生成答案、改稿、写求职信前**读一遍本画像**即可。

---

## 0. 边界

- 行为画像**不替代**硬技能匹配（`smart_score` / `decision_context`），它是「软维度」的补充层。
- 不要求必须做正式测评。没有 PI/DISC/MBTI 报告也能用——用「自我评估」填模板即可。
- 不虚构性格。画像里的每一条都应是你**真实**的工作方式，面试被追问要经得起 STAR 检验。

---

## 1. 三类框架速查（任选其一填，或混用）

### 1.1 PI（Process & People / 行为特质）
| 维度 | 高分区典型表现 | 低分区典型表现 |
|------|----------------|----------------|
| **A 主导性** | 主导、直接、快决策 | 协作、倾听、共识驱动 |
| **B 进取性** | 竞争、外向、多线推进 | 稳健、从容、单线深耕 |
| **C 耐心/条理** | 严谨、流程化、重细节 | 灵活、容忍模糊、快迭代 |
| **D 服从/规则** | 守规则、重合规 | 挑战规则、破局导向 |

### 1.2 DISC
| 类型 | 关键词 | 面试/简历里的信号 |
|------|--------|-------------------|
| **D 支配** | 结果、决断、掌控 | 主导项目、拿结果、推动落地 |
| **I 影响** | 沟通、振奋、人际 | 跨团队拉齐、汇报演讲、建关系 |
| **S 稳健** | 协作、可靠、耐心 | 长期打磨、稳定交付、支持他人 |
| **C 审慎** | 分析、精确、系统 | 数据驱动、方法论、风险把控 |

### 1.3 MBTI（常用 4 轴）
- **E/I** 能量来源：外向（讨论中充电）/ 内向（独处中充电）
- **S/N** 信息偏好：实感（细节/现状）/ 直觉（模式/可能性）
- **T/F** 决策：思考（逻辑）/ 情感（价值/人）
- **J/P** 节奏：判断（计划闭环）/ 感知（开放探索）

> 不必全填。挑**能解释你职业选择**的 1–2 个轴写清即可（例如「I + T：偏好独立深度分析、用数据而非情绪决策」）。

## 2. 画像模板（填到 `career-context.md` 或本文件末尾）

```markdown
## 我的行为画像
- 框架：PI / DISC / MBTI / 自我评估（选一）
- 沟通风格：[例：书面严谨、口头直接，偏好先对齐目标再展开]
- 决策风格：[例：数据驱动 + 快速小步验证，避免长周期空转]
- 压力下的工作风格：[例：模糊需求下先搭最小闭环，而非等完美方案]
- 团队角色：[例：技术侧 owner，擅长把模糊需求翻译成可执行拆分]
- 核心驱动力：[例：把复杂系统做简单、可见的结果落地]
- 易踩的摩擦点：[例：在纯汇报型/强政治环境里效率低]
```

## 3. JD 关键词 ↔ 行为风格映射（写答案/改稿时查表）

> 当 JD 出现下列词，结合你的画像判断是 **强匹配（写入答案）** 还是 **潜在摩擦（提前准备说辞）**。

| JD 常见词 | 隐含行为要求 | 若你画像偏… → 强匹配写法 | 潜在摩擦（准备话术） |
|-----------|--------------|---------------------------|----------------------|
| 快节奏 / 高速迭代 | 高 B、高 D、容模糊 | 「在 X 周内需上线，我用最小闭环先跑通再补」 | 偏 C 稳健→强调「快但不乱，有 checkpoint」 |
| 跨团队 / 协同 / 推动 | 高 I、高 A | 「独立拉齐 3 个团队对齐目标，推动落地」 | 偏 I 弱→用具体协作案例补 |
| owner / 主导 / 负责 | 高 A、高 D | 「从 0 到 1 主导 X，对结果负责」 | 偏 S→强调「在授权范围内兜底到底」 |
| 数据驱动 / 严谨 / 风控 | 高 C | 「建了 X 指标体，用数据收敛决策」 | 偏 D→补「也知道何时该拍板」 |
| 创新 / 探索 / 不确定性 | 高 B、高 P | 「在 0 信息下先建假设再验证」 | 偏 C/J→强调「探索中有节奏收口」 |
| 抗压 / 高强度 | 高 B、高 D | 「在 X  deadline 同时扛 Y，如期交付」 | 偏 S→说「靠拆解+优先级稳住」 |

## 4. 织入指引（三处落地）

### 4.1 求职信（cover letter）
- 读画像的「沟通/决策/团队角色」，**一句话点出你与岗位行为要求的契合**（不要列测评分数，要写成叙事）。
- 例：「我习惯先对齐目标再展开、用最小闭环快速验证——这与贵岗『快节奏迭代』高度合拍。」

### 4.2 简历（CV）
- 在 `match_reasons` 对应的项目里，**补一个行为侧证据**：不仅写「做了 X」，写「如何推动/如何协同/如何抗压拿下」。
- 与 `resume-guide.md` §3.5（优势点强化）联动：硬优势 + 行为优势双写。

### 4.3 面试（STAR）
- 每个 STAR 答案除「做了什么」，补「**我以什么工作方式做成**」——这往往比结果更让面试官记住。
- 摩擦点准备：用 §3 表把「潜在摩擦」转成「我有意识补强的点」（例：「我偏深度分析，所以刻意用周会同步进度弥补信息差」）。
- 与 `interview-prep.md` 联动：读 `scored_results.json` 的 `risks` **之后**，再叠加本画像决定「哪些行为优势要主动亮、哪些摩擦要主动化解」。

---

## 5. 维护

- 画像随经历演进：每完成一个阶段（拿 offer / 复盘一次失败），回看本文件，更新「团队角色 / 摩擦点」。
- 与 `career-memory.md` 不同：本文件是**稳定的行为特质**，记忆文件是**事件流水**；二者互补。
