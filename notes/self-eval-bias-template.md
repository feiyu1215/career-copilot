# 自评偏见模板（Self-Eval Bias Template）

> **用途**：任何对 career-copilot 的**自评类报告**（SkillLens 深度评测 / 架构评审 / 能力盘点 / 升级前后对比 / M4 类动态回归）**必须在报告顶部包含本模板的「独立性声明」+「偏差自检」两段**。
>
> **定位**：方法学护栏，不新增运行时负担。与 `notes/addition-criteria.md` 同源——确保「可靠」对外可信，而不只是作者自称。
>
> **哲学依据**：(A) 提升自评可靠性；(B) 修复「自己出题、自己阅卷」的高概率认知故障（M4 4/4 证明力有限即此症的实证，见 `notes/skilllens_deep_review.md` §自评局限与偏差披露）。
>
> **强制级别**：自评类报告的**必填头部**，非可选附录。不填视为 DoD 不达标（文档更新项缺失）。

---

## 一、自评元信息（必填，置顶）

| 字段 | 值 |
|------|-----|
| 评测对象 | （skill 名 + 版本 / commit） |
| 评测日期 | YYYY-MM-DD |
| 评测方式 | LLM 深度评测 / 脚本启发式 / 混合 |
| 证据层级 | SYNTHETIC-MECHANISM / LLM-REAL / 混合 |
| 总评结论 | （verdict + 分数） |
| 可信度自评 | 高 / 中 / 低（必须给，且与下方独立性声明一致） |

---

## 二、独立性声明（必填，置顶）

> 回答三个问题，逐一显式回答，不回避、不套话。

**1. 谁是评分人？**
（人 / 模型 / 工具 —— 若是 LLM，注明 provider + model）

**2. 评分人与被评对象的关系？**
- [ ] 评分人 = skill 作者本人 → **零独立性，最高风险**
- [ ] 评分人 = 同团队 / 同项目成员 → 低独立性
- [ ] 评分人 = 外部独立评审 → 高独立性
- [ ] 自动脚本 / LLM（取决于脚本是否由作者编写评分标准）

**3. 出题人与阅卷人是否同一人？**
- eval 用例（如 M4 的 `expected_output`）由谁编写？与评分人是否同一人？
- 若同一人 → 必须标注「**自己出题、自己阅卷**」，并写明其证明力上限：
  > 证明的是「该模型（如 agnes-2.0-flash）能 follow 本 skill」，**≠「跨模型 / 跨时间可靠」**。

**独立性结论**：（独立 / 部分独立 / 零独立）+ 对结论可信度的具体影响说明。

---

## 三、偏差自检（必填，逐项过）

对每条偏差，勾选「已排查」或「不适用」，并在备注写具体做法 / 证据。未排查的偏差**必须**在报告正文「Weaknesses」中显式承认，不得隐瞒。

| # | 偏差类型 | 定义 / 触发信号 | 自检结果 | 缓解动作 / 证据 |
|---|---------|---------------|---------|---------------|
| B1 | 三重同源 / 零独立性 | 作者 = 出题人 = 阅卷人 | ☐ 已排查 ☐ 不适用 | （如：请外部评审 / 显式标注限制） |
| B2 | 确认偏差 | Strengths 自夸、Weaknesses 轻描淡写（原稿 5 条弱点仅扣 20 即此症） | ☐ 已排查 ☐ 不适用 | （如：主动列 ≥3 条真实短板并给证据） |
| B3 | 边界凑分 | 总分恰好压线（如恰好 =80）；单点 ±1 即变 verdict | ☐ 已排查 ☐ 不适用 | （如：报告「距线差 X 分」而非「压线通过」） |
| B4 | 未验证事实 | 文中数字 / 结论未实际核实（如「75 文件」未数即写） | ☐ 已排查 ☐ 不适用 | （如：用 `find` / `git` 核实后更正） |
| B5 | 自我服务归因 | 成功归设计、失败归外部（模型抽风 / 端点限流） | ☐ 已排查 ☐ 不适用 | （如：区分「skill 回归」vs「生成方差」再归因） |
| B6 | 近因偏差 | 过度看重最近一次改动，忽略历史上下文 | ☐ 已排查 ☐ 不适用 | （如：对照 `notes/audit-borrowing-plan.md` 历史） |
| B7 | 框架效应 | 把弱点包装成特点（「偏密」说成「详尽」） | ☐ 已排查 ☐ 不适用 | （如：弱点直说，不粉饰） |

---

## 四、强制承诺（必填，置底）

- [ ] 本报告已显式标注独立性缺陷，未隐瞒。
- [ ] 所有分数 / 结论均可追溯到具体证据（文件 / 用例 / 运行记录）。
- [ ] 若 evidence 为 LLM-REAL，已说明 provider / model / run 次数；若为 SYNTHETIC-MECHANISM，已说明是离线验证非 live。
- [ ] 结论定级（Good / Excellent）与独立性声明一致——**零独立时不自称 Excellent**。

---

## 五、使用约定

- 本模板是**自评类报告的强制头部**，不是可选附录。
- 不填「独立性声明」或「偏差自检」的自评报告，视为 DoD 不达标（文档更新项缺失）。
- 本模板本身不评分、不阻止产出——它强制的是「诚实披露」，与 skill「**隐蔽的 fallback 比显式报错更危险**」哲学一致。
- 模板随 `notes/addition-criteria.md` 演化；新增偏差类型时同步更新本表，并在 `audit-borrowing-plan.md` 留痕。
